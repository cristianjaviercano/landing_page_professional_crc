ZERO — An Operations Platform for Running University Courses Without Losing Track of Anyone

Built to run my own university course load: five subjects, roster uploads, grading, attendance, and a research group — replacing what used to be a scatter of spreadsheets, printed exams, and manual roster imports with one local system.

Course & Roster Management AI-Assisted Grading Computer-Vision Exam Scanning Python / REST API

The situation

Five courses, hundreds of students, and every semester started from a blank spreadsheet

Running multiple sections every semester meant re-building rosters, grade sheets, and attendance trackers from scratch each time — with early warning signs of a struggling student buried somewhere in a spreadsheet nobody checked until it was too late to act.

Grading physical exams added another manual bottleneck: scan, read, transcribe, repeat — for every student, every exam.

What was built

One local platform, six operational modules

Roster & bulk import

Imports official CSV/Excel course rosters directly, no manual re-entry per section.

Early-risk indicators

Synthetic status badges (on track / critical risk) computed from current grade and attendance, so a struggling student surfaces before finals.

AI-assisted rubric grading

Structured rubric templates evaluated with AI assistance, injected directly into the grade sheet instead of transcribed by hand.

Camera-based exam scanning

A vision scanner reads answer sheets from a phone camera and writes the grade straight into the system — no manual transcription step.

Research-group management

Tracks the university research group's members and meetings alongside the teaching workload, in the same system.

REST API + local dashboard

A local HTTP server backs a single-page dashboard UI — everything runs on the instructor's own machine, no external dependency mid-semester.
