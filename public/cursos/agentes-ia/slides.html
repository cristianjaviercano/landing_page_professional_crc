💬 Chatbot Tradicional vs 🤖 Agente de IA

💬 El Chatbot (Consultor de Pasillo)

Solo autocompleta texto basado en su entrenamiento general. No ejecuta acciones reales en tus archivos ni en tu computadora.

Prompt ➔ LLM ➔ Salida de texto pasiva

Piensa, decide y actúa. Usa herramientas en Python, abre bases de datos, realiza cálculos matemáticos exactos y genera entregables probados.

🧩 Los 4 Pilares Técnicos de la Anatomía del Agente

🧠 1. El Cerebro

Modelo Backend de IA encargada del razonamiento.

  • Google Gemini 2.5 Pro / Flash
  • Anthropic Claude 3.5 Sonnet

📜 2. El Contrato

`system_instructions` / Persona.

  • Define rol y especialización
  • Límites éticos y tono
  • Reglas de formato (APA 7)

🧰 3. Herramientas

Python Tools & Function Calling.

  • Funciones nativas asíncronas
  • Lectura de docstrings y args
  • Acceso al sistema y la web

📝 4. Memoria

Estado de Trabajo & Contexto.

  • Historial de conversación
  • Archivo rector `context.md`
  • Variables persistentes
💡 Regla de Oro en Python: El agente decide cuándo invocar una función leyendo únicamente su nombre, los tipos de parámetros y el docstring ("""...""").

🔌 Protocolo Abierto MCP & Google NotebookLM

¿Qué es el Model Context Protocol (MCP)?

Es el "enchufe universal" de la IA (estándar abierto) que conecta agentes a bases de datos, APIs y herramientas sin código frágil custom.

# Ejemplo: Orquestación del Bucle Autónomo PR3
async def bucle_linea_produccion(prompt_inicial: str):
    borrador = await operario_redactor.chat(prompt_inicial)
    aprobado = False
    
    while not aprobado:
        # Supervisor Q1 independiente audita vs fuentes reales
        dictamen = await supervisor_q1.chat(f"Auditar:\n{borrador}")
        if "APROBADO" in dictamen.text().upper():
            aprobado = True
            print("✅ Manuscrito aprobado 100% sin alucinaciones.")
        else:
            print("🔄 Inconformidad detectada. Reprocesando autónomamente...")
            borrador = await operario_redactor.chat(f"Corrige:\n{dictamen.text()}")
            
    return borrador

📌 Reglas de Oro & Conclusiones

💡 Las 4 Reglas de Oro del Creador de Agentes

  1. Especialización Única: Jamás obligues a un solo agente a resolver todo el problema.
  2. Independencia del Auditor: El redactor NUNCA debe inspeccionar su propio trabajo.
  3. Parametrización Rectora: Define reglas léxicas y de formato en context.md.
  4. Conexión Estándar: Conecta fuentes de conocimiento reales usando servidores MCP (NotebookLM).
